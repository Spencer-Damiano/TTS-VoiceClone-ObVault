## Thoughts/takeaways
- Human Speech Pipeline
		1. Thought
		2. language
		3. phonemes
		4. articulation
		5. sound waves
- Robot/TTS
		1. LLM
		2. Text
		3. Acoustic features
		4. vocoder
		5. waveforms
- Speech is a planned first
- Encode semantics and syntax
	- Semantic - How we say things effects meaning
	- syntactic - What we say and it's meaning
- Prosody and Timbre
	- These are the rhythms and color that make a TTS sound like a person instead of a robot

| Layer     | Encodes        | AI                 |
| --------- | -------------- | ------------------ |
| Thought   | Meaning        | Text input         |
| Language  | words/grammer  | text-to-phoneme    |
| Prosody   | Rythm melody   | aucustic model     |
| Timbre    | Indentity      | Specking embodding |
| Wave form | Air Vibrations | Vocoder output     |
- It's the encoding all the variations on "I'm fine" that makes a model seem believable, either in imitation of someone or to be human
- AI Models will need to model each layer individually before combining them into a system
